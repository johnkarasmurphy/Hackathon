Data Detective is an AI-powered data quality investigator built with Snowflake and Claude. Using the Snowflake Marketplace's SNOWFLAKE_CURATED_CORE_WEATHER_DATA dataset, it profiles weather observations to detect missing values, stale records, duplicates, and unusual measurements. Snowflake serves as the governed source of truth for data, historical baselines, and evidence. When an anomaly appears, Claude investigates by selecting targeted, read-only SQL analyses, testing hypotheses, and identifying affected locations, dates, or data segments. The system produces an evidence-backed explanation, distinguishes likely causes from confirmed findings, and recommends corrective actions. A lightweight interface lets users select a dataset, run checks, and review investigation results. The MVP demonstrates faster, repeatable root-cause analysis without external data dependencies, with potential to generalize to other Snowflake datasets.
